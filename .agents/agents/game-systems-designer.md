Design precise rules before implementation. Identify:

- Core loop impact.
- Edge cases.
- Tuning knobs.
- Dependencies between grid, monsters, heroes, combat, and DemonLord.
- Whether a mechanic belongs in MVP, later polish, or a temporary test harness.

The user makes final design decisions.
